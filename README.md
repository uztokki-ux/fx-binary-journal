# 📊 FX Binary Journal — дневник трейдера бинарных опционов

**Бесплатный веб-дневник для трейдеров бинарных опционов на форекс.**
Работает прямо в браузере, ничего не нужно скачивать и устанавливать.

## 🔗 Открыть дневник

**👉 [uztokki-ux.github.io/fx-binary-journal](https://uztokki-ux.github.io/fx-binary-journal/)**

## ✨ Возможности

- 📝 Учёт сделок (CALL/PUT) с направлением, экспирацией, результатом
- 📅 Календарь торговых дней (прибыльные / убыточные / без сделок)
- 📈 Статистика по дням недели, торговым сессиям и времени экспирации
- 🎯 Постановка и отслеживание целей (день / неделя / месяц)
- 🧮 Калькулятор риск-менеджмента (расчёт размера ставки, цепочки отыгрыша)
- 🔁 Симулятор винрейта со сложным процентом
- 🖼️ Прикрепление скриншотов сделок (хранятся локально в браузере)
- 🌙 Тёмный интерфейс в стиле терминала

## 🔒 Приватность

Все данные (сделки, скриншоты, настройки) хранятся **только в твоём браузере**
(localStorage) — ничего не отправляется на сервер, регистрация не нужна.
Это значит, что данные привязаны к конкретному браузеру и устройству, где ты
их вносил, и не синхронизируются между разными людьми или устройствами.

## 🚀 Как пользоваться

1. Перейди по ссылке: https://uztokki-ux.github.io/fx-binary-journal/
2. Добавь страницу в закладки браузера — заходить через них удобнее всего
3. Начни вносить сделки во вкладке «Новая сделка»

Ссылка работает в любом браузере на телефоне или компьютере, GitHub-аккаунт
для использования дневника не требуется.

## 🛠️ Технологии

Один самодостаточный HTML-файл: HTML, CSS, JavaScript, Chart.js для графиков.
Без бэкенда и баз данных — всё на стороне клиента.

## 📌 Дисклеймер

Проект создан для личного учёта сделок и анализа собственной статистики.
Не является финансовым советом и не гарантирует прибыльность торговли.
